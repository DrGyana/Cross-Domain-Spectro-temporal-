# Cross-Domain-Spectro-temporal-
Cross-Domain Spectro temporal Representation Learning for Deepfake Video Forensic

This repository contains the implementation used in the paper:

"Cross-Domain Spectro temporal Representation Learning for Deepfake Video Forensics"

Authors
Gyana Ranjana Panigrahi, Jagjit Singh Dhatterwal, Kalpesh. H. Vandra, Kiran Malik, Suvendu Kumar Nayak, Ramdas Khomane

Requirements
Python 3.11

Install packages

pip install -r requirements.txt

Run
python main.py
